NEON Torrent 3.6.0 (15 Nov 2026)
- Videos: paste a YouTube (or Vimeo, X, Instagram, Reddit, TikTok and many more) link into the ADD box. Pick the format (MP4, MKV, MOV, AVI, MPEG, WEBM, FLV, or audio only as MP3, M4A, OPUS, OGG, WAV, FLAC) and the quality: only the resolutions the video really has, up to 4K, or the MP3 bitrate. It downloads in DOWNLOADS with pause, resume and the queue.
- One-click updates. NEON checks GitHub for a new version now and then. When there is one, a green arrow appears in the title bar.
- Click the arrow to see what is new, then UPDATE NOW: the download shows its progress. INSTALL & RESTART installs it (Windows asks once) and starts the new NEON, which shows what changed.
- Every update is checked before it installs: GitHub's SHA-256 for the file, that it is NEON's own package, and its version. Help > Check for updates checks right away.

NEON Torrent 3.5.1 (15 Nov 2026)
- One ADD box for everything: paste a magnet, info-hash, .torrent link, a direct file link or a web page. NEON works out what it is.
- Downloads (an IDM-style download manager): many connections per file, pause and resume, resume after a restart, a queue, a speed limit and a start time. Finished files get Mark-of-the-Web; programs are flagged.
- Web pages: NEON lists the files, magnets and .torrent links on the page and you tick what to download. The page is only read as text: nothing on it runs.
- Search: one search across all your sources. Internet Archive is built in; add Torznab (Jackett, Prowlarr), RSS feeds, search pages, or sites that open in your browser. Quickwords search one source ("ia ubuntu"). Results are not filtered by topic; sources you add are marked "not verified by NEON".
- Zero pop-ups: NEON has no web page engine, so ads, scripts, frames and pop-ups never run. Search lists only real magnets and .torrent links.
- A .torrent your browser saves to Downloads: NEON offers to add it.

NEON Torrent 3.2.0 (14 Nov 2026)
- PC to PC with a short code: press GET SHORT CODE in File Sharing and tell your friend the code (like 7-tiger-crystal). They type it in Transfer > Connect to PC, anywhere in the world. No long link to copy, no account.
- The code is checked with SPAKE2 through a public relay that never learns the code or the link; each code allows one try and expires after 15 minutes. Files stay end-to-end encrypted and the PC still has to be allowed.
- File Transfer: an upload cancelled on the receiving PC now reports Cancelled on the sender instead of a connection error.
- Windows light mode: Connect to PC's file list, the Paired devices table and the text box were white with pale text; they are dark like the rest of NEON.
- File Sharing: the TO PHONE | FROM PHONE and LAN | INTERNET switches always stay in view; on a short window only the network panel below the QR code scrolls (the whole column could scroll them out of sight).
