NEON Torrent 3.1.0 (12 Nov 2026)
- Magnet links from the browser open in NEON again: "Use NEON" registered a python.exe that does not exist in the installed app. NEON now registers NeonTorrent.exe and repairs that registration by itself at start.
- Magnets without trackers (common from websites) no longer stall at "Fetching the file list" while DHT is off: NEON asks its public trackers for them. Peers are still Shield-filtered.
- The Malwarebytes allow-list path in Preferences > Shield shows NeonTorrent.exe.

NEON Torrent 3.0.0 (12 Nov 2026)
- PC to PC: two PCs with NEON transfer files and text, on the same Wi-Fi or anywhere over the internet. Copy the pair code on one PC (File Sharing > COPY PAIR CODE), paste it on the other (Transfer > Connect to PC). End-to-end encrypted like the phone.
- Paired devices: a PC you allow can be remembered by its key and connects without the Allow prompt next time (Transfer > Paired devices).
- Text from the PC: type in the TEXT panel to send text to the connected phone or PC. The phone shows it in its Text tab with a Copy button.
- Menu bar: File, View, Transfer, Settings and Help.
- cloudflared is now part of Setup, so File Sharing over the internet works on a PC without it.
- File Sharing fits short screens: the left column scrolls instead of growing the window. The status reads READY.

NEON Torrent 2.1.1 (12 Nov 2026)
- Magnet links work: Setup registers NEON Torrent for magnet links and .torrent files, and lists it in Settings > Default apps.
- When another app (e.g. uTorrent) still opens magnet links, NEON asks once at start whether to take over. Preferences > General > Magnet links does it any time.

NEON Torrent 2.1.0 (11 Nov 2026)
- Setup works on every PC: it installs to C:\Program Files\NEON Torrent by default (it used to need an F: drive and quit without one). An upgrade keeps the folder of the installed copy.
- Setup.exe with the NEON icon; it opens the same installer.
- First start: installed in Program Files, NEON suggests your own Downloads\NEON folder for downloads.

NEON Torrent 2.0.0 (6 Nov 2026)
- File Transfer: send text from the phone. Paste or type in the phone's new Text tab and tap Send text.
- On the PC, TEXT FROM PHONE shows how many are new; click it to open the chat panel.
- Every message has a one-click COPY at its top right, and any part can be selected with the mouse.
- Text is end-to-end encrypted like files, plain text only, up to 20,000 characters, never saved to disk.

NEON Torrent 1.1.0 (6 Nov 2026)
- Native Windows app: NeonTorrent.exe is now compiled (Nuitka). Python, a browser and the VC++ Redistributable are no longer needed.
- New Windows Installer (MSI) setup: installs for all users and shows in Programs and Features.
- Setup detects an installed version, compares versions, shows this update log, and offers Upgrade or Full uninstall.
- User Agreement, Privacy Policy and Disclaimer in Setup. No certificates or keys of the author are shipped.
- New neon installer design.
- Errors are logged to data\error.log again.
- Closing the window asks: Minimize to tray or Exit, with "Remember my choice" (Preferences > General > Close button).
