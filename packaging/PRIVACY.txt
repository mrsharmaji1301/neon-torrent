NEON Torrent: privacy and terms of use
=======================================

NEON Torrent is a personal BitTorrent client with phone file sharing. Please read this before installing.

PRIVACY
- No telemetry, no analytics, no account. NEON never sends usage data anywhere.
- Your data stays on this PC, in the "data" folder inside the install folder: settings, torrent list,
  resume data, learned Shield blocks and logs. Uninstalling keeps it; delete the folder to remove it.
- Network connections NEON makes:
  * peers and trackers of the torrents you add (peers in a swarm can see your IP address; that is how
    BitTorrent works);
  * public IP-range lists the Shield downloads to filter VPN and datacenter peers;
  * optional VirusTotal hash lookups, only if you enter your own API key (only the file hash is sent);
  * File Sharing: a local server on your Wi-Fi while sharing is on, and, in internet mode, a temporary
    Cloudflare quick tunnel. Shared files are end-to-end encrypted (X25519 + ChaCha20-Poly1305) and the
    key exists only in the QR code, so neither the network nor Cloudflare can read them.
- NEON reads your antivirus' local detection log (Malwarebytes) to learn which peers to block. It never
  uploads it.
