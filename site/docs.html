Adding Torrents

NEON Torrent supports multiple flexible ingestion paths:

  • Drag and Drop: Drag one or more .torrent files directly onto the transfer table.
  • Direct Paste (Ctrl+V): Copy a magnet link or HTTP(S) torrent URL anywhere and press Ctrl+V inside the app window.
  • Link Dialog (Ctrl+N): Opens the link input bar to accept magnet links, bare info-hashes (40-character hex or 32-character base32), or web URLs.
  • File Picker (Ctrl+O): Standard multi-select file dialog for local .torrent files.
  • CLI / Automation: Pass URLs via command line: run.bat "magnet:?xt=urn:btih:...". If NEON is already running, arguments are safely routed to the active window via a local user socket.

Pause vs. Stop

Unlike clients that blur the distinction between pausing and stopping, NEON Torrent offers clear, deterministic states:

Pause (Space)

Temporary state. Finishes downloading blocks currently in flight to avoid wasted bandwidth, while holding peer connections ready to resume immediately.

Stop (Ctrl+Shift+S)

Hard disconnect. Immediately severs all peer connections, closes open file handles on disk, ceases seeding, and persists in the stopped state across app restarts until you manually resume it.

Disk Full Management & Moving Data

When a drive fills up during a large download, NEON Torrent stops writing and tells you what it needs:

Automatic Upload-Only Transition

If a target drive fills up, libtorrent immediately stops writing and flips the torrent into upload-only mode. The transfer status displays Disk full in red, reporting both the space required and space remaining.

Once you clear disk space, the torrent resumes downloading automatically. Alternatively, right-click the item and choose Move data (or open Torrent settings) to seamlessly relocate the files to another drive without re-downloading.

Speed Optimizations & FLASH MODE

Built from the ground up for maximum throughput without compromising privacy:

  • Multi-Tier Tracker Announcing: Standard libtorrent implementations stop querying trackers after the first responsive tier. NEON announces to every tracker in every tier simultaneously, unlocking swarms where primary trackers are blocked.
  • Payload-Only Upload Cap: TCP/IP download acknowledgments (ACKs) are excluded from the upload limiter. A small upload cap such as the default 24 KiB/s no longer starves your own piece requests.
  • Rapid Peer Ramp-Up: Optimized connection rate parameters, short connect timeouts, and multi-threaded piece hashing ensure swarms reach peak speed in seconds.

⚡ FLASH MODE (Ctrl+Shift+F)

A manual, one-click accelerator designed for large or stubborn torrents. FLASH MODE turns on read-only DHT (serving no lookup requests for external swarms), enables Local Peer Discovery (LSD), injects high-availability public booster trackers, and raises connection capacity up to 1,500 peers.

Note: FLASH MODE automatically resets to off when the application restarts to maintain default file-only network hygiene.

The Shield Connection Map (Ctrl+M)

Press Ctrl+M or click the Shield icon on the title bar to open the live Connection Map. This window gives you transparent visibility into every packet:

  • Live Peer Table: View active peers, IP, Autonomous System Number (ASN), network owner, country flag, BitTorrent client identification, connection source (Tracker, PEX, or DHT), direction (incoming/outgoing), and live transfer rates.
  • Refused Peers Log: Inspect refused connections and see the exact defensive rule triggered (e.g. Datacenter IP, VPN exit range, or Malwarebytes detection).
  • Learned Block Management: Browse all addresses and subnets absorbed from Malwarebytes with a one-click unblock option.
  • Network Data: ASN and IP intelligence powered by the public iptoasn.com dataset, refreshed weekly in the background.

Per-Torrent Controls (Ctrl+T)

Click any torrent's name or press Ctrl+T to access granular settings that apply instantly:

Bandwidth & Limits

Individual download/upload limits, maximum peer connection caps, and upload slot throttling.

Priority & Streaming

Sequential downloading (ideal for previewing video streams), first and last pieces prioritized, and queue prioritization (top, up, down, bottom).

Seeding & Ratio Rules

Configurable share ratio stop thresholds, super-seeding mode for initial releases, and force start overrides.

Integrity & Trackers

Force recheck, re-announce to all tiers, add custom trackers, and "Skip hash check" to verify existing files directly upon seeding.
