Questions & Answers

How does the Shield stop antivirus alerts?

Most torrent-triggered antivirus alerts come from connections to VPN exit nodes, datacenter IPs and flagged networks — not from actual malware in your files. By default the Shield refuses peers in the X4BNet VPN and datacenter ranges before contact. On a real alert history, 12 of 13 flagged peers would have been refused this way. The Shield also reads Malwarebytes’ detection log every 2 seconds, so an IP it flags is never contacted again. A new address can still cause one alert before the Shield learns it.

Can NEON guarantee 100% virus-free downloads?

No — and any client that claims otherwise is misleading you. BitTorrent piece verification confirms data integrity (the file matches the torrent hash), but it cannot tell you whether the original file is safe. What NEON Torrent does control: Download Guard inspects every file name for disguised executables, double extensions, hidden Unicode direction overrides and shortcut files — and skips them before a single byte is requested. It also applies Mark-of-the-Web so Windows SmartScreen checks any program you do run. Pro users get optional Microsoft Defender and VirusTotal hash scans for an extra layer.

What is FLASH MODE?

FLASH MODE is a one-click speed boost you activate with Ctrl+Shift+F (or the toolbar button). It adds every file source at once: read-only DHT (it asks about your own torrents and serves nobody else’s lookups), Local Peer Discovery, a few public booster trackers and up to 1,500 connections. Peers found this way are still Shield-filtered. The mode resets automatically on restart so your everyday settings stay untouched. FLASH MODE is a Pro feature.

What happens if my drive fills up?

NEON Torrent switches to upload-only mode and shows a red “Disk full” status on affected torrents, with the space needed and the space free. Once you free space, downloading resumes automatically. You can also use Move data to relocate files to another drive without re-downloading.

Does VirusTotal upload my files?

No. With your own VirusTotal API key, NEON sends only the SHA-256 hash of a program for lookup; the file itself is never sent.

Does it work with Malwarebytes?

Yes. Shield reads the MwacDetections log every 2 seconds and absorbs any IPs that Malwarebytes flags. The blocked address is never contacted again. If you want Malwarebytes to stay completely silent about NEON Torrent network activity, add NeonTorrent.exe to the Malwarebytes allow list (Settings → Allow List).
