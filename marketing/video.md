# 60-second demo video

**Demo file:** the official Ubuntu ISO torrent from ubuntu.com.

| Time | Shot | Voice-over / on-screen text |
|---|---|---|
| 0:00–0:05 | Open NEON Torrent. Show the transfer list and Shield button. | “This is NEON Torrent, a Windows BitTorrent client with peer filtering and file checks.” |
| 0:05–0:12 | Add the Ubuntu ISO torrent. Show the new transfer row. | “I’m adding an Ubuntu ISO torrent from ubuntu.com.” |
| 0:12–0:20 | Open the Shield connection map. Move across live peers and network details. | “Shield shows connected peers and filters known VPN and datacenter ranges before contact by default.” |
| 0:20–0:28 | Show refused peers and learned blocks, then return to the transfer list. | “You can see why a peer was refused and review blocks learned from Malwarebytes.” |
| 0:28–0:36 | Open torrent details and show file list / progress. | “The torrent’s pieces are checked against its hashes. That confirms the data matches the torrent, not that the uploader’s files are safe.” |
| 0:36–0:44 | Show Guard status and scan result after completion, where available in the prepared demo. | “Download Guard skips risky file names before download, adds Mark-of-the-Web, and scans with Defender when Defender is active.” |
| 0:44–0:52 | Demonstrate pause and resume; show status chips and speed cards. | “Pause or resume a transfer, filter the list by status, and tune per-torrent settings.” |
| 0:52–1:00 | End card with app window and a clear caveat. | “NEON helps you see and manage connections and file checks. Keep your antivirus on; no client can prove an upload is safe.” |

## Shot list

1. Launch NEON Torrent and frame the main transfer window.
2. Add an Ubuntu ISO torrent from ubuntu.com.
3. Open Shield’s connection map and show live peer details.
4. Show refused peers and learned blocks.
5. Open the torrent’s details and show file progress.
6. Show the Guard status after the demo download completes; do not imply a scan happened if the result is not present.
7. Pause and resume the transfer, then show status filters.
8. Close on the caveat that hashes verify torrent data, not file safety.
