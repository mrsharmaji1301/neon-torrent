# Press pitch emails

## TorrentFreak

**Subject:** Story idea: a torrent client built around peer filtering and file checks

Hi TorrentFreak team,

I made NEON Torrent, a Windows BitTorrent client focused on peer visibility and safer file handling. Its Shield refuses known VPN and datacenter ranges before contact by default and can learn from Malwarebytes blocks. Download Guard skips several risky file names and types before download, adds Mark-of-the-Web, and can scan with Microsoft Defender when it is active.

The approach has limits: a newly flagged peer can still cause one alert before Shield learns it, and no client can establish that an uploader’s file is safe. NEON’s connection map and documented security audit may make a useful look at how these protections work in practice.

Would you be interested in reviewing the product or speaking with the NEON team?

Regards,
NEON team

## Neowin

**Subject:** Review suggestion: NEON Torrent for Windows

Hi Neowin team,

I made NEON Torrent, a Windows desktop BitTorrent client with peer filtering, file checks, and detailed transfer controls. Shield filters known VPN and datacenter ranges before contact by default, learns from Malwarebytes blocks, and shows peer status and refusal reasons in a connection map. Download Guard skips risky file names and types before download, adds Mark-of-the-Web, and can scan with Microsoft Defender when it is active.

NEON also includes per-torrent limits, queue controls, status filters, and disk-full handling. We’re careful not to call it malware-proof: a new flagged address can still cause one alert, and the client cannot prove an uploader’s file is safe.

Would your team consider a review of NEON Torrent? We can provide product details and answer technical questions.

Regards,
NEON team
